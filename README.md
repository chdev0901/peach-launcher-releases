# 🍑 Peach Launcher (피치 런처)

SoftPeach가 만든 마인크래프트 런처 + 모드 관리자예요. 이 저장소는 **설치 파일과 자동 업데이트 배포용**이에요.

## 설치
1. [최신 릴리스](https://github.com/chdev0901/peach-launcher-releases/releases/latest)에서 `PeachLauncher-Setup-<버전>.exe`를 받아 실행해요.
2. 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.
3. 예전 Craft Launcher가 깔려 있으면 자동으로 바뀌고, 세계·설정은 그대로 옮겨져요.

## 업데이트
한 번 설치하면 런처가 켜질 때 새 버전을 알아서 받아요. 왼쪽 아래에 "새 버전 준비됐어요"가 뜨면 **다시 시작해서 업데이트**를 누르거나, 그냥 런처를 껐다 켜면 돼요.
